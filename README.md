# Zoll

**Zoll** — это современный язык разметки, созданный как прямая альтернатива Markdown с фокусом на **явность**, **отсутствие избыточности** и **расширенные возможности** для работы с текстом.

> 🟢 **Язык:** Zoll (файлы `.zoll`)  
> 🛠 **Редактор:** Zol (проект-компаньон для работы с Zoll)

---

## Мотивация

Markdown хорош, но обладает рядом системных проблем:

- **Избыточность:** `**жирный**` и `__жирный__` делают одно и то же.
    
- **Случайные срабатывания:** написание `*100#` в заметках ломает разметку, требует экранирования.
    
- **Ограниченность:** нет встроенных терминов, макросов, сложных ссылок, гибких таблиц.
    
- **Неоднозначность:** разные диалекты MD ведут себя по-разному.

Zoll решает эти проблемы системно, а не заплатками.

---

## Философия

- **Один символ — одна задача.** Никаких дублирующих конструкций.
    
- **Явность важнее краткости.** Синтаксис читается как осмысленная разметка, а не как случайный набор символов.
    
- **Безопасность по умолчанию.** `*100#` не сломает документ — теги начинаются только с `#:`.
    
- **Расширяемость.** Термины, макросы, шаблоны и кастомные блоки делают Zoll пригодным для книг, документации, заметок и веба.

---

## Быстрый пример

#1# Что такое Zoll?

Zoll — это **язык разметки** с поддержкой //курсива//, **подчёркивания** и ~~зачёркивания~~.

==Важно:== этот текст подсвечен.

Можно использовать термины:

[~HTTP:протокол передачи данных]

А затем ссылаться на них: {~HTTP:подробнее в документации}

Ссылки бывают разные:

- Внутренняя: [[Другой файл]]
- Внешняя: [https://example.com](https://www.google.com/search?q=https://%D0%9F%D1%80%D0%B8%D0%BC%D0%B5%D1%80)
- С картинкой: !<width:400>{logo.png}

А это спойлер:

!!Спойлер:Нажми, чтобы увидеть скрытый текст!!

И макрос времени: {:date}

## Синтаксис

### 1. Встроенное форматирование

|**Символ**|**Назначение**|**Пример**|**Примечание**|
|---|---|---|---|
|`// //`|Курсив|`//текст//`||
|`** **`|Жирный|`**текст**`||
|`__ __`|Подчёркивание|`__текст__`||
|`'' ''`|Верхний индекс|`''текст''`||
|`,, ,,`|Нижний индекс|`,,текст,,`||
|`~~ ~~`|Зачёркивание|`~~текст~~`||
|`== ==`|Подсветка|`==текст==`||
|`++ ++`|Вставка|`++текст++`|Для отображения изменений|
|`-- --`|Удаление|`--текст--`|Для отображения изменений|
|`%% %%`|Комментарий|`%%текст%%`|Не отображается в финальном документе|
|`$ $`|Формула (строчная)|`$x+y$`|Поддержка математики|
|`$$ $$`|Формула (блочная)|`$$x+y$$`|По центру|

---

### 2. Спойлеры

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`!! !!`|Строчный спойлер|`!!название:текст!!`|
|`!!! !!!`|Блочный спойлер|`!!!название:текст!!!`|

> Спойлеры показывают содержимое только при взаимодействии (клик/наведение). В статическом выводе отображаются как скрытые блоки.

---

### 3. Ссылки и изображения

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`[[ ]]`|Внутренняя ссылка|`[[Файл]]`|
|`[[ ]]( )`|Ссылка с названием|`[[Файл]](текст)`|
|`[ ]( )`|Внешняя ссылка|`[url](текст)`|
|`>[[ ]]`|Ссылка на цитату|`>[[цитата]]`|
|`!< >{ }`|Изображение с параметрами|`!<width:300>{image.png}`|

> Параметры изображения указываются внутри `<>` через двоеточие.

---

### 4. Термины, шаблоны и макросы

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`[~ ]`|Определение термина|`[~HTTP:протокол передачи данных]`|
|`{~ }`|Использование термина|`{~HTTP:текст для всплывающей подсказки}`|
|`[$ ]`|Создание шаблона|`[$quote:«<>»]`|
|`{$ }`|Использование шаблона|`{$quote:текст}`|
|`{: }`|Макрос|`{:date}`|

**Термины** — это глобальные определения, которые можно использовать в любом файле проекта. При наведении на `{~термин}` показывается описание из `[~термин]`.

**Макросы** — динамические вставки. Редактор может предоставлять любые макросы: дата, время, прогноз погоды, пользовательские скрипты и т.д.

---

### 5. Специальные объекты

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`[! ]`|Callout-блок (примечание)|`[!Важно:текст]`|
|`[? ]`|Клавиши/сочетания|`[?:Ctrl+C]`|
|`^`|Сноска|`[^1:текст сноски]`|

> Callout-блоки — это визуально выделенные блоки для предупреждений, заметок, подсказок.

---

### 6. Блоки и структура

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`#N#`|Заголовок уровня N|`#1# Заголовок`|
|`-`|Ненумерованный список|`- элемент`|
|`1.`|Нумерованный список|`1. элемент`|
|`` ` ``|Строчный код|`` `код` ``|
|`---`|Горизонтальный разделитель|`---`|
|`>`|Цитата|`> текст`|
|`> <`|Блочная цитата|`>текст<`|
|`#:тег`|Тег|`#:важно`|

> Заголовки поддерживают **любой уровень** (хоть 32) — ограничения задаются реализацией редактора.

---

### 7. Таблицы

Поддерживаются стандартные таблицы с разделителями `|`. Выравнивание настраивается **как для всей колонки, так и для отдельной ячейки**.

#### Выравнивание колонок

Используются стандартные маркеры:

|**Символ**|**Назначение**|
|---|---|
|`:---`|Левое выравнивание колонки|
|`---:`|Правое выравнивание колонки|
|`:---:`|Центральное выравнивание колонки|

#### Выравнивание отдельных ячеек

Для каждой ячейки можно задать своё выравнивание, поставив `:` **вплотную** к разделителю `|`:

- `|: текст` → левое выравнивание (двоеточие сразу после `|`)
- `текст :|` → правое выравнивание (двоеточие сразу перед `|`)
- `|: текст :|` → центрирование (двоеточия с обеих сторон)

**Важные правила:**

- Между `:` и `|` **не должно быть пробелов** — иначе `:` считается обычным содержимым ячейки.
- Между содержимым ячейки и `|` допускается **не более одного пробела** (для читаемости). Если пробелов больше — они становятся частью содержимого.
- Отступы всей таблицы от текста не обязательны, но если используются, то **только один пробел** перед первой `|`.

Пример:

```
|: левое | центр :| |: правое :| |
|: ещё левое |: ещё центр :| |правое:|
```

---

### 8. Правила синтаксиса

#### Пробелы

**Пробелы запрещены** между управляющими символами и текстом:

- ✅ `**жирный**`
- ❌ `** жирный **`

#### Вложенность

Вложенность поддерживается. Порядок применения — **от внешнего к внутреннему**:

- `**//текст//**` → сначала жирный, потом курсив
- Результат: жирный курсив

#### Завершённость конструкций

Конструкция работает **только при полном завершении**:

- ✅ `**текст**` → жирный
- ❌ `**текст` → обычный текст (две звёздочки как символы)

#### Экранирование

Символ `\` экранирует **только следующий за ним символ**:

- `\#текст` → `#текст` (не тег)

## Отличия от Markdown

|**Аспект**|**Markdown**|**Zoll**|
|---|---|---|
|Жирный|`**` и `__`|только `**`|
|Теги|`#тег` (конфликт с `#100`)|`#:тег` (явно)|
|Термины|нет|`[~]` / `{~}`|
|Макросы|нет|`{:}`|
|Таблицы|выравнивание только колонок|колонки + каждая ячейка|
|Ссылки|один синтаксис|явные: внутренние, внешние, на цитаты|
|Спойлеры|нет (только через HTML)|встроенные `!! !!` и `!!! !!!`|
|Callout-блоки|нет|`[!]`|
