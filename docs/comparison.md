# Отличия от Markdown

|**Аспект**|**Markdown**|**Zoll**|
|---|---|---|
|Жирный|`**` и `__`|только `**...))`|
|Теги|`#тег` (конфликт с `#100`)|`#:тег` (явно)|
|Термины|нет|`[~]` / `{~}`|
|Макросы|нет|`{:}`|
|Таблицы|выравнивание только колонок|колонки + каждая ячейка|
|Ссылки|один синтаксис|явные: внутренние, внешние, на цитаты|
|Спойлеры|нет (только через HTML)|встроенные `!!...}` (строчный) и `!!!...}` (блочный)|
|Callout-блоки|нет|`[!]`|
|Комментарии|`<!-- -->`|`%%...}` (строчный), `%%%...}` (блочный)|
|Формулы|только через LaTeX-плагины|`$...))` (строчный), `$$...}` (до конца строки), `$$$...}` (блочный)|
