# Синтаксис Zoll

## Быстрый пример

\#1# Что такое Zoll?

Zoll — это \*\*язык разметки)) с поддержкой //курсива)), \__подчёркивания)) и \~~зачёркивания)).

==Важно:)) `< этот текст подсвечен.`

Можно использовать термины: `[~HTTP:протокол передачи данных]`

А затем ссылаться на них: `{~HTTP:подробнее в документации}`

Ссылки бывают разные:

- Внутренняя: `[[Другой файл]]`
- Внешняя: `[https://www.google.com](Google search)`
- С картинкой: `!<width:400>{logo.png}`

А это спойлер: `Текст !! скрытое содержимое }`

Или спойлер с заголовком: `!!спойлер: скрытый текст до конца строки }`

Блочный спойлер на несколько строк:

```
!!!спойлер:
тут скрытое содержимое
}
```

А это комментарий: `Текст %% эта часть не видна }`

И блочный комментарий:

```
%%%
весь этот блок скрыт
}
```

И макрос времени: `{:date}`

И метаданные документа:

```
@@
title: Название документа
author: Иван
}
```
  - Содержимое блока метаданных разбирается отдельным проходом (в редакторе — отдельным потоком), основной парсер помечает только границы блока.

## Синтаксис

### 1. Встроенное форматирование (inline)

Inline-маркеры работают **строго внутри одной строки**. Открытие и закрытие — на той же строке. Закрываются маркером `))`.

|**Символ**|**Назначение**|**Пример**|**Примечание**|
|---|---|---|---|
|`//` ... `))`|Курсив|`//текст))`||
|`**` ... `))`|Жирный|`**текст))`||
|`__` ... `))`|Подчёркивание|`__текст))`||
|`''` ... `))`|Верхний индекс|`''текст))`||
|`,,` ... `))`|Нижний индекс|`,,текст))`||
|`~~` ... `))`|Зачёркивание|`~~текст))`||
|`==` ... `))`|Подсветка|`==текст))`||
|`++` ... `))`|Вставка|`++текст))`|Для отображения изменений|
|`--` ... `))`|Удаление|`--текст))`|Для отображения изменений|
|`$` ... `))`|Формула (строчная)|`$x+y))`|LaTeX-математика внутри строки|
|`%` ... `))`|Комментарий (строчный)|`%это не видно))`|Не отображается в выводе, прямо в тексте|
|`!` ... `))`|Спойлер (строчный)|`!скрыто))`|Скрыто до взаимодействия, прямо в тексте|

---

### 2. Строчные маркеры (line-level)

Строчные маркеры (line, close) действуют **от маркера до конца строки**. Могут располагаться в любом месте строки — и в начале, и в тексте. Закрываются маркером `}`; без закрытия действуют до конца строки автоматически.

> Маркер `%%` — всегда строчный, где бы он ни стоял. Для комментария прямо в тексте есть отдельный маркер `%` (раздел 1).

|**Символ**|**Назначение**|**Пример**|**Примечание**|
|---|---|---|---|
|`%%` ... `}`|Комментарий до конца строки|`Текст %% это не видно }`|Не отображается в выводе|
|`$$` ... `}`|Формула (блочная) до конца строки|`x = 5 $$ \sqrt{x} }`|LaTeX, выравнивание по центру|
|`!!` ... `}`|Спойлер до конца строки|`Текст !! скрытое содержимое }`|Скрыто до взаимодействия|
|`!!заголовок:` ... `}`|Спойлер с заголовком|`!!важно: скрытый текст }`|Заголовок виден всегда, содержимое скрыто|

**Примеры:**
```
Это видимый текст %% а это комментарий, его не видно}
Формула: E = mc^2 $$ \int_{-\infty}^{\infty} e^{-x^2} dx}
Обычный текст !! а это неожиданный спойлер до конца строки}
!!спойлер: тут скрытое содержимое после двоеточия}
```

---

### 3. Блочные маркеры (block-level)

Блочные маркеры располагаются **строго на отдельных строках, без отступов** (ровно в начале строки). Открывают и закрывают многострочные блоки. Закрываются маркером `}` в начале новой строки.

> Три символа (`%%%` / `$$$` / `!!!`) — это блочный маркер, а не «строчный, стоящий в начале строки». Количество символов задаёт уровень (см. раздел 9). `@@` — отдельный блочный маркер метаданных: у него нет inline/line-вариантов, и ровно два символа делают его блочным.

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`%%%` ... `}`|Многострочный комментарий|Строка с `%%%` открывает блок, строка с `}` закрывает. Содержимое между ними не отображается.|
|`$$$` ... `}`|Многострочная формула|Строка с `$$$` открывает блок LaTeX, строка с `}` закрывает.|
|`!!!` ... `}`|Многострочный спойлер|Строка с `!!!` (возможно с заголовком `!!!название:`) открывает блок, строка с `}` закрывает.|
|`!!!название:` ... `}`|Многострочный спойлер с заголовком|Заголовок виден всегда, содержимое блока скрыто.|
|`@@` ... `}`|Метаданные документа|Строка с `@@` открывает блок метаданных, строка с `}` закрывает.|

> **Содержимое метаданных не разбирается основным парсером.** Блок помечается целиком (одним спаном) и передаётся отдельному обработчику — в редакторе это отдельный поток, который читает `title` и остальные поля.

**Примеры:**

```
%%%
Этот текст полностью скрыт
Его не видно в финальном документе
}

$$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
}

!!!спойлер:
Это скрытое содержимое спойлера
На нескольких строках
}

!!!                     ← заголовок не указан
Тоже спойлер, но без заголовка
Просто скрытый блок
}

@@
title: Мой документ
author: Иван
tags: парсер, метаданные
}
```

> Блоки не могут быть вложены: маркер блока распознаётся только ровно в начале строки, отступы исключены.

### 5. Термины, шаблоны и макросы

|**Символ**|**Назначение**|**Пример**|
|---|---|---|
|`[~ ]`|Определение термина|`[~HTTP:протокол передачи данных]`|
|`{~ }`|Использование термина|`{~HTTP:текст для всплывающей подсказки}`|
|`[$ ]`|Создание шаблона|`[$quote:«<>»]`|
|`{$ }`|Использование шаблона|`{$quote:текст}`|
|`{: }`|Макрос|`{:date}`|

**Термины** — это глобальные определения, которые можно использовать в любом файле проекта. При наведении на `{~термин}` показывается описание из `[~термин]`.

**Макросы** — динамические вставки. Редактор может предоставлять любые макросы: дата, время, прогноз погоды, пользовательские скрипты и т.д.

### 8. Таблицы

Поддерживаются стандартные таблицы с разделителями `|`. Выравнивание настраивается **как для всей колонки, так и для отдельной ячейки**.

#### Выравнивание колонок

Используются стандартные маркеры:

|**Символ**|**Назначение**|
|---|---|
|`:---`|Левое выравнивание колонки|
|`---:`|Правое выравнивание колонки|
|`:---:`|Центральное выравнивание колонки|

#### Выравнивание отдельных ячеек

Для каждой ячейки можно задать своё выравнивание, поставив `:` **вплотную** к разделителю `|`:

- `|: текст` → левое выравнивание (двоеточие сразу после `|`)
- `текст :|` → правое выравнивание (двоеточие сразу перед `|`)
- `|: текст :|` → центрирование (двоеточия с обеих сторон)

**Важные правила:**

- Между `:` и `|` **не должно быть пробелов** — иначе `:` считается обычным содержимым ячейки.
- Между содержимым ячейки и `|` допускается **не более одного пробела** (для читаемости). Если пробелов больше — они становятся частью содержимого.
- Отступы всей таблицы от текста не обязательны, но если используются, то **только один пробел** перед первой `|`.

Пример:

```
|: левое | центр :| |: правое :| |
|: ещё левое |: ещё центр :| |правое:|
```

### 9. Уровни маркеров

Каждый маркер в Zoll относится к одному из уровней — это основа архитектуры языка:

| Уровень | Где располагается | Закрытие | Примеры |
|:---|:---|:---|:---|
| **Inline** | В любом месте строки | `))` | `** ... ))`, `// ... ))`, `% ... ))`, `$ ... ))`, `! ... ))` |
| **Line (close)** | В любом месте строки | `}` либо до конца строки автоматически | `%% ... }`, `$$ ... }`, `!! ... }` |
| **Line (not-close)** | Только в начале строки | Не требуется | `#1 ...`, `#:тег`, `> ...`, `- ...`, `1. ...`, `---`, `\| ...` |
| **Block** | Только на отдельной строке, без отступов | `}` в начале строки | `%%% ... }`, `$$$ ... }`, `!!! ... }`, `@@ ... }` |

**Железное правило: тип маркера определяется самим маркером, а не его позицией в строке.**

Для семейств `%`, `$`, `!` уровень задаётся **количеством повторяющихся символов**:

- 1 символ (`%`, `$`, `!`) → **inline**: `%комментарий))`, `$x+y))`, `!спойлер))`
- 2 символа (`%%`, `$$`, `!!`) → **line (close)**: `%%комментарий}`, `$$ формула}`, `!! спойлер}`
- 3 символа (`%%%`, `$$$`, `!!!`) → **block**: `%%%` / `$$$` / `!!!` на отдельной строке

`@@` — единственный блочный маркер, не следующий счёт-паттерну: метаданные существуют только как блок, поэтому ровно два символа `@@` сразу задают блок. Одиночный `@` и тройной `@@@` — не маркеры.

Это визуально разные маркеры: `%комментарий))` — inline, `%%комментарий}` — строчный, `%%%` — блочный. Маркер не «становится» другим из-за позиции — позиция лишь внутренняя деталь парсера. Поэтому `%%` в середине строки остаётся строчным маркером, а для inline-комментария используется `%`; блочный `%%%` не конфликтует ни с одним из них.

**Пример Block-level:**
```
%%% <- только маркер на одной строке
... <- тут какой-то текст
} <- закрывается одной скобкой в начале строки
```

Это разделение — не просто синтаксическое удобство, а **ключевое архитектурное решение**. Благодаря ему редактор может обрабатывать правку любой строки изолированно, без перепарса всего файла:

- Inline-правка → перепарсить одну строку
- Line-правка → перепарсить одну строку
- Block-правка → обновить стек блоков (O(число затронутых блоков), не O(весь файл))

### 10. Правила синтаксиса

#### Тип маркера

Тип маркера определяется **самим маркером** (символом и их количеством), а не позицией в строке. Позиция никогда не меняет тип: `%%` — всегда строчный, `%` — всегда inline, `%%%` — всегда блочный. Благодаря этому не бывает «неожиданной» разметки: что написано, то и работает.

#### Пробелы

**Пробелы запрещены** между управляющими символами и текстом:

- ✅ `**жирный))`
- ❌ `** жирный ))`

#### Вложенность

Вложенность поддерживается. Порядок применения — **от внешнего к внутреннему**:

- `**//текст))` → сначала жирный, потом курсив
- Результат: жирный курсив

*Здесь не нужно писать множество )) символов по причине того, что это вложенность, маркер сможет закрыть всё сразу.*

#### Завершённость конструкций

Конструкция работает **только при полном завершении**:

- ✅ `**текст))` → жирный
- ❌ `**текст` → обычный текст (две звёздочки как символы)

#### Экранирование

Символ `\` экранирует **только следующий за ним символ**:

- `\#:текст` → `:текст` (не тег)
