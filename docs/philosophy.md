# Философия Zoll

## Мотивация

Markdown хорош, но обладает рядом системных проблем:

- **Избыточность:** `**жирный**` и `__жирный__` делают одно и то же.
    
- **Случайные срабатывания:** написание `*100#` в заметках ломает разметку, требует экранирования.
    
- **Ограниченность:** нет встроенных терминов, макросов, сложных ссылок, гибких таблиц.
    
- **Неоднозначность:** разные диалекты MD ведут себя по-разному.

Zoll решает эти проблемы системно, а не заплатками.

---

## Философия

- **Один символ — одна задача.** Никаких дублирующих конструкций.
    
- **Явность важнее краткости.** Синтаксис читается как осмысленная разметка, а не как случайный набор символов.
    
- **Безопасность по умолчанию.** `*100#` не сломает документ — теги начинаются только с `#:`.
    
- **Расширяемость.** Термины, макросы, шаблоны и кастомные блоки делают Zoll пригодным для книг, документации, заметок и веба.
